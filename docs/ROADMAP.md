# Roadmap

These are planned directions. Versions and dates will be set as work is ready.

| Horizon | Direction |
| --- | --- |
| Near term | Smoke-test the Windows prerelease installer on a clean machine and verify that an installed build detects the next release through GitHub. |
| Next | Make update downloads and installation reliable and improve how users discover and configure file workflows. |
| Later | Explore karaoke key and tempo adjustment, metadata-based renaming and further platform packaging. |

See the [changelog](changelogs/README.md) for shipped work and the [backlog](todo.md)
for individual tasks, experiments and deferred ideas.
