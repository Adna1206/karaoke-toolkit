# Roadmap

These are planned directions. Versions and dates will be set as work is ready.

| Horizon | Direction |
| --- | --- |
| Near term | Prepare a Windows release by closing the [distribution gaps](distribution/distribution-licensing.md), testing the installer and establishing a reliable download path. |
| Next | Make update downloads and installation reliable and improve how users discover and configure file workflows. |
| Later | Explore karaoke key and tempo adjustment, metadata-based renaming and further platform packaging after Windows distribution is established. |

See the [changelog](changelogs/README.md) for shipped work and the [backlog](todo.md)
for individual tasks, experiments and deferred ideas.
