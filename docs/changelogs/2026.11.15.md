2026-11-11

## Upgrading on Windows

Close the old app, extract and run the 2026.11.15 portable build once, then close
it and run Setup. The portable build copies surviving settings, favourites,
recipes and recovery indexes to `%LOCALAPPDATA%\KaraokeToolkitData` before Setup
replaces the old install folder. See the [upgrade instructions](../distribution/updates.md).

## Changes

- Windows settings, favourites, recipes and recovery indexes live in
  `%LOCALAPPDATA%\KaraokeToolkitData`, outside the folder Windows Setup replaces.
- Unknown preference keys are removed on the next desktop save. Unsupported
  saved values fall back individually so other preferences still load.
- Windows Setup creates a desktop shortcut alongside the Start menu shortcut.
- Explorer integration is enabled by default on first Setup for new profiles.
  Setup preserves the existing registration when it finds saved preferences or
  a previous Setup decision, including when the user has removed the menu entry.
