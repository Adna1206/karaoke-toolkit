# 2026.11.18

2026-11-18 · Windows x64 prerelease

## Recovery and file tools

- Start checks for interrupted runs in the main window before opening the
  processing view. The footer shows the check in progress, and startup gives
  the main window time to draw before offering recovery.
- Recovery offers **Abandon interrupted run…** for a run you no longer wish to
  resume. This stops prompts for that run and retains its journals, backups and
  changes already made. Pending file transactions can still block writes to
  protect retained data.
- Flattening can remove empty Windows folders marked read-only. It reports
  isolated cleanup failures and continues with other folders. Move errors
  identify the affected paths and include the operating system's reason.
- Added **Add Track ID Separator** and **Remove Track ID Separator** to the desktop
  app, CLI, MCP and recipes.

## Desktop

- Track Grouping and Tagging previews open in the main workspace. Back
  preserves your input selection and asks before discarding edits. Track
  Grouping also supports expanding or collapsing the destination tree and
  resizing the issues panel.
- Recipe Builder combines recipe selection and naming, and gives new recipes
  clearer placeholders. Tagging has an editable pattern list, Refresh and
  bulk row selection.
- Dialogs share footer spacing and Escape handling. Menu commands and related
  windows use matching icons. Long footer messages scroll automatically.
- **Rip CD+G (Experimental)…** opens from **Tools** when enabled in Settings.
  Existing ripping favourites still work.
- The update checker shows the result in the same dialog. FFprobe retries once
  if it receives malformed output.

## Windows downloads

This prerelease provides an unsigned Windows x64 installer. Experimental disc
ripping still requires a compatible drive and remains unverified on physical
hardware. See [crash recovery](../user/crash-recovery.md) and
[disc ripping](../user/disc-ripping.md) for details.
