# 2026.11.17

2026-11-16 · Windows x64 beta

- Added **Group by Track ID** to File & Folder Tools, CLI, and MCP. Group
  files or whole folders by numeric ranges or trailing digits, with
  optional parent folders and a destination preview.
- Added an opt-in startup update check under Settings → General. It runs
  after the main window opens and only reports an available update.
- Switched update checks to the Toolkit GitHub Releases feed, including
  published beta releases for the installed channel.
- Renamed the alphabetical grouping and flattening tools and clarified what
  each operation moves.
- Added crash recovery to standalone alphabetical grouping and flattening.
  Recovery settings for these operations and track grouping support SHA-256
  (default), xxHash128, metadata only, and no verification. Interrupted runs
  without content verification or with batch resume disabled are available
  for manual review.
- Standardized activity rows across desktop operations and moved the home
  picker, run screen, and live activity table into separate views.
- Routine test runs reuse build outputs and remove successful test fixtures.
  Publishing removes successful staging after verifying package checksums.
- Replaced the bundled FFmpeg and FFprobe runtimes with pinned Conda-forge
  9.0.2 LGPL builds for Windows x64, Linux x64 and Apple Silicon. Windows Setup
  downloads and installs the Visual C++ x64 redistributable when needed.
  Portable Windows builds require it to be installed separately.
- Labelled the bundled OpenH264 licence under **About → Third-party notices**
  as **FFmpeg · OpenH264 · BSD-2-Clause**.
- Fixed intermittent truncated FFprobe output during concurrent media work.
  Added coverage confirming that WebM tagging preserves the encoded VP9 video
  and Opus audio streams.

See the [publishing guide](../distribution/publishing.md#sharing-a-windows-test-build)
for installer and source downloads.

The first GitHub beta provides a Windows x64 installer. Linux and Apple Silicon
downloads are planned for later releases.

Existing journals without a verification mode are read as SHA-256. See the
[Windows upgrade instructions](2026.11.15.md#upgrading-on-windows) if upgrading
from a version earlier than 2026.11.15.
