# 2026.11.16

2026-11-11

- Settings groups General preferences into collapsible cards and combines audio
  and video options in one Encoding tab.
- Windows Explorer controls appear first in Settings → Integrations.
- Desktop list boxes and selection highlights share rounded corners.
- The Windows main title bar includes the app icon and File, Tools, and Help
  menus. Secondary windows blend their title bars into the page and show the app
  icon. Dropdown commands use larger text.
- The Tools and operation lists line up and use matching heights for single-line
  rows, including rows with a favourite button. Desktop
  headings use a consistent type scale, and tool descriptions and Settings help
  use shorter wording. The Settings page heading matches the menu.
- The desktop activity log has aligned columns, a shaded header, and row
  separators. Scrolling up pauses auto-follow, and the mouse wheel can scroll
  away from the bottom after processing finishes.
- Live conversion activity uses paths relative to the displayed source folder
  and shows reasons for skips and failures. Routine successes appear in the
  totals and run report. Separate CUE and TXT writing messages also appear
  in CLI and MCP live progress.
- Item and Total progress bars are thicker and centered beside their labels.
- Desktop file pickers show the formats accepted by the selected operation.
  Incompatible selections are flagged before Start. CUE/TXT creation and
  filename cleanup prompt for folders. Opening supported non-ZIP archives from
  Explorer suggests Convert Archive to ZIP.
- TXT track listings and CUE sheets support fixed names or `{folder}` templates
  with filename previews in Settings.
- Remember last input folder lets Add Files and Add Folders reopen at the last
  picked location across restarts. Explorer launches use the clicked item.
- Added a versioned changelog.

See the [Windows upgrade instructions](2026.11.15.md#upgrading-on-windows) if
you are upgrading from a version earlier than 2026.11.15.
