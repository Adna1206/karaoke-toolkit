# 2026.11.16

2026-11-11

- Settings groups General preferences into collapsible cards and combines audio
  and video options in one Encoding tab.
- Windows Explorer controls appear first in Settings → Integrations.
- Desktop list boxes and selection highlights share rounded corners.
- TXT track listings and CUE sheets support fixed names or `{folder}` templates
  with filename previews in Settings.
- Remember last input folder lets Add Files and Add Folders reopen at the last
  picked location across restarts. Explorer launches use the clicked item.
- Added a versioned changelog.

See the [Windows upgrade instructions](2026.11.15.md#upgrading-on-windows) if
you are upgrading from a version earlier than 2026.11.15.
