# Support

Start with the [Quick Start](../README.md#quick-start) and
[documentation index](README.md). If you have access to the repository and its
issue tracker is available, use it for ordinary bugs and usage questions.
Include your Toolkit version, operating system and the steps you took.
Use fictional names or redact personal information from logs and samples.

For vulnerabilities, follow the [security policy](SECURITY.md).
